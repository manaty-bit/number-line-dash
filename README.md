# 数直線ダッシュ / Number Line Dash

MANATY LAB · 4.1.0

中学1年「正の数・負の数」の加法・減法を、数直線上で位置と移動を確かめながら学ぶ教材です。画面と賞状は日本語・英語に対応します。

## 遊び方

- ステージ0では左右の操作を練習します。失敗しても何度でも試せます。
- ステージ1は加法、2は減法、3は加減の混合、4は複合問題です。複数の移動があるときは、強調された項の到着点を順に確定します。0を加える・引くときは、その位置で決定します。
- 矢印ボタンか、数直線上でのクリック・ドラッグで位置を動かします。数直線にフォーカスすると左右キーで1目盛ずつ移動できます。
- 学習ステージを10問完了すると銀賞状、すべての問で各移動を最初の判定で正解すると金賞状です。誤答した問も訂正してから進めます。全学習ステージで銀以上を取得すると、記録画面から卒業証明書を発行できます。
- 60秒チャレンジは式全体の終点を答えます。誤答で−5秒、3連続正解目から正解ごとに＋1秒です。正解数の自己ベストを端末に記録します。

## 授業で使う

「足す数の符号」と「引く数の符号」を見比べ、同じ数を足すときと引くときの移動の向きを説明します。例として、2＋(−3) と 2−(−3) を数直線で比較し、最後に紙で 2−(−3)＝2＋(+3)＝5 と書きます。導入ではステージ0を使い、続けてステージ1・2を各自のペースで進めます。

## データと賞状

- 賞状の名前は任意です。ニックネームや無記名でも保存できます。名前は賞状の編集中にだけ画面内で保持され、入力内容の外部送信はありません。
- 端末のブラウザに、無記名の賞状履歴、練習の完了、ステージの最高成績・挑戦回数、チャレンジの自己ベストを保存します。共有端末では「この端末の記録を消去」を使ってください。保存済みPNGは端末のファイル管理で削除できます。
- 端末時刻と提出番号は提出物を見分けるための情報です。画像や端末時刻は変更できるため、真正性や不正防止は保証できません。
